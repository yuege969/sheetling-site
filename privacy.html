隐私政策

Sheetling（PDF 转 Excel · 本地处理）· Chrome 扩展 · 最后更新：2026-11-24

我们不收集任何数据。你的 PDF 不会离开你的电脑，扩展也没有能力把它发出去—— 没有申请任何网络权限，页面的 CSP 又只允许它读自己包内的文件。

1. 收集什么

什么都不收集。具体到每一类：

2. 技术上为什么做不到

不是"我们承诺不发"，是结构上没有这个能力：

// manifest.json
{
  "permissions": [],
  "host_permissions": [],
  "content_security_policy": {
    "extension_pages": "script-src 'self'; object-src 'self'; connect-src 'self'"
  }
}
  • 没有 host_permissions，扩展读不到任何网站的数据；没有内容脚本，也改不了你访问的页面。
  • connect-src 'self' 是浏览器层的网络白名单：扩展页面只允许 fetch 自己包内的文件（解析 PDF 用的 cMap 和字体）， 向任何外部域名发请求都会被 CSP 当场拦掉——这一步不经过我们的代码，代码写错也发不出去。
  • 没有申请 downloads：保存文件用的是页面内的 <a download> + Blob URL。
  • 没有内容脚本，所以读不到你访问的任何网页。
  • PDF 解析库（pdf.js）、字体和中文 cMap 全部打包在扩展本地，不从 CDN 取一个字节。

3. 你可以自己验证

三步，五分钟：

  1. 打开扩展，按 F12 或右键 →「检查」，切到 Network 面板。
  2. 保持面板打开，拖一个 PDF 进去转换。
  3. Network 面板应该一条请求都没有。下载的那一下是浏览器本地行为，不产生请求。

我们自己也测过：三个真实 PDF（英文对账单 3 页、中文电子发票、中文餐饮小票），转换过程分别用时 95ms / 89ms / 79ms，网络请求数都是 0。

English summary

Sheetling – PDF to Excel (local conversion) · Chrome extension · Last updated: 2026-11-24

We collect no data. Your PDF never leaves your computer, and the extension has no technical ability to send it anywhere — it requests no network permissions, and its Content-Security-Policy only allows it to read files inside its own package.

  • What is collected: nothing. No files, no page contents, no usage statistics, no crash logs, no device information, no account.
  • Why it is impossible: manifest.json declares "permissions": [] and "host_permissions": [], so the extension cannot read the pages you visit, and the page CSP sets connect-src 'self', so the browser blocks any request to an outside domain — that check happens in Chrome, not in our code. The PDF engine (pdf.js), fonts and CJK cmaps are bundled locally — nothing is fetched from a CDN.
  • Where files go: the .xlsx is generated in your browser and saved through a Blob URL to your own download folder. Nothing is uploaded.
  • Verify it yourself: open DevTools → Network, convert a PDF, and observe zero requests.
  • Third parties: no analytics, ads, crash reporting or A/B testing SDKs. If you installed the extension from the Chrome Web Store, the store handles installation and payment data under its own policy.
  • Children: not directed to children under 13; no personal data is collected from anyone.
